# Python Selenium Automation Assignments

This repository contains the **Python Selenium Automation codes** for the four assignments covering different web element identification, location, and interaction techniques using Selenium WebDriver.

## 📚 Assignments Covered

### Assignment 1: Web Element Identification
**Covered by:** Roney Ghosh

Identify and locate different web elements on a webpage using Selenium locators:

- `By.ID`
- `By.NAME`
- `By.TAG_NAME`
- `By.LINK_TEXT`
- `By.CLASS_NAME`

**Example:** Locate the username field using ID, password field using Name, and a link using Link Text.

---

### Assignment 2: Multiple Element Identification
**Covered by:** Simantini Das

Identify multiple elements on a webpage and work with the list of elements using Selenium.

Topics covered:

- Locating multiple web elements
- Using `find_elements()`
- Working with lists of web elements
- Extracting and printing text from multiple elements

**Example:** Find all links on a webpage and print their text.

---

### Assignment 3: CSS Selector Challenge
**Covered by:** Srijani Bishnu

Locate web elements using **CSS Selectors**, including wildcard selectors for elements having varying or dynamic attribute values.

Topics covered:

- CSS Selectors
- Attribute selectors
- Wildcard selectors
- Dynamic attributes

**Example:** Use a CSS wildcard selector to locate elements whose ID starts with `user_`.

---

### Assignment 4: Child Nodes Using CSS
**Covered by:** Shivraj Bhattacherjee

Identify and locate child/nested web elements using CSS selectors and interact with the required element.

Topics covered:

- Parent and child elements
- Nested HTML elements
- CSS child selectors
- Locating elements inside a specific parent element

**Example:** Locate a button inside a specific `<div>` using a CSS child selector.
